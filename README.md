A tiny TypeScript program that writes a single sentence to `/output/entry.txt` — the one line that could have replaced an entire pointless meeting. It builds the line from a verdict, a fact, and a kill clause, compares it against a bench of alternates, and writes the winner.

## Run it

```sh
node main.ts
```
